# Financeiro

Planejamento, análise e decisões financeiras da Dorinhos.

## Estrutura

- `CLAUDE.md` — Configuração de skills e preferências
- `MEMORY.md` — Índice de memória
- `memory/glossary.md` — Termos financeiros, análise e KPIs

## Como Usar

Abra este projeto no Claude Code. Ele carregará automaticamente `CLAUDE.md` com as skills específicas para gestão financeira.

## Skills Disponíveis

- **finance:financial-statements** — Análise da saúde financeira
- **finance:variance-analysis** — Análise de budget vs realizado
- **finance:journal-entry** — Registrar transações financeiras
- **data:analyze** — Análise profunda de dados financeiros
- **product-management:roadmap-update** — Planejamento financeiro
- **product-management:metrics-review** — Revisão de KPIs financeiros
- **product-management:stakeholder-update** — Apresentação para liderança

## Padrões

- Foco em decisão estratégica
- Métricas de ROI e performance
- Visibilidade para liderança
